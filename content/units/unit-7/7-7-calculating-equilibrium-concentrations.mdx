When initial concentrations and K are known, the equilibrium concentrations can be found by tracking how the reaction changes each species. An ICE table organizes **Initial**, **Change**, and **Equilibrium** values.

<TopicLab unitId={7} topicNumber="7.7" title="ICE Table Solver" />

<LessonSection title="1. Build the change row from stoichiometry" description="The balanced coefficients link every change" defaultOpen>

For aA + bB ⇌ cC, if the reaction proceeds forward by x, the changes are −ax, −bx, and +cx. Equilibrium concentrations are initial values plus changes. Use the balanced equation to keep the changes proportional.

<WorkedExample title="Worked example: set up an ICE table">
For A ⇌ B, start with [A] = 1.00 M and [B] = 0.00 M. If x reacts, the equilibrium values are [A] = 1.00 − x and [B] = x. Therefore Kc = x/(1.00 − x). The next step is to substitute the known K and solve for x, then check that the result is physically possible.
</WorkedExample>

</LessonSection>

<LessonSection title="2. Solve and verify the physical meaning" description="Algebra is not the final check">

After substituting the equilibrium row into K, solve the resulting equation. If a quadratic results, evaluate physically meaningful roots only. Reject any root that gives a negative concentration or exceeds the available amount. When the change is small compared with the initial concentration, an approximation may sometimes be used, but verify it against the stated tolerance.

<WorkedExample title="Worked example: check a proposed root">
An algebraic solution gives x = 1.20 M for a reactant that initially had only 0.50 M and is consumed in a 1:1 step. That root is impossible because it would produce a negative equilibrium reactant concentration. Choose a physically valid root and substitute it back into K.
</WorkedExample>

<LessonSection title="3. Solve a quadratic and test the small-change approximation" description="An algebraic answer is only valid if the chemistry permits it">

Consider `A(g) ⇌ 2B(g)` with `[A]₀ = 0.500 M`, `[B]₀ = 0`, and `Kc = 0.200`. Let x M of A react. The equilibrium concentrations are `[A] = 0.500 − x` and `[B] = 2x`, so:

`0.200 = (2x)²/(0.500 − x)`

Rearranging gives `4x² + 0.200x − 0.100 = 0`. The positive root is `x ≈ 0.135 M`; the negative root is physically impossible. Therefore `[A]eq ≈ 0.365 M` and `[B]eq ≈ 0.270 M`. Substitution gives `(0.270)²/0.365 ≈ 0.200`, so the result is internally consistent.

<WorkedExample title="Worked example: decide whether x is small">

If you approximate `0.500 − x ≈ 0.500`, then `0.200 ≈ 4x²/0.500`, giving `x ≈ 0.158 M`. But `x/0.500 × 100% ≈ 31.6%`, which is not small. The approximation is not justified; use the quadratic result. A common classroom guideline is to check whether x is at most about 5% of the initial concentration, but the actual error should be checked when accuracy matters.

</WorkedExample>

<LessonSection title="4. Start an ICE table when products are already present" description="Choose the sign of x from Q versus K before writing changes">

When both reactants and products are present initially, do not automatically assume the reaction proceeds forward. Calculate Q first. For `A(g) ⇌ 2B(g)`, if `[A]₀ = 0.200 M`, `[B]₀ = 0.300 M`, and `Kc = 1.00`, then `Q = (0.300)²/0.200 = 0.450`. Because Q < K, the net reaction proceeds right, so A decreases by x and B increases by 2x.

If instead the initial mixture had `[A]₀ = 0.200 M` and `[B]₀ = 0.800 M`, then `Q = (0.800)²/0.200 = 3.20 > K`. The reaction proceeds left. You can define x as the reverse change: A increases by x and B decreases by 2x. The algebra is valid either way, but the direction determines the signs in the change row.

<WorkedExample title="Worked example: use Q to choose the ICE signs">

For `A ⇌ 2B` with `Kc = 1.00`, `[A]₀ = 0.200 M`, and `[B]₀ = 0.800 M`, use `Q = 3.20` to predict a shift left. The ICE row is therefore `+x` for A and `−2x` for B, giving `[A]eq = 0.200 + x` and `[B]eq = 0.800 − 2x`. The physically allowed range is `0 ≤ x ≤ 0.400 M`; any root outside this interval would imply a negative concentration.

</WorkedExample>
