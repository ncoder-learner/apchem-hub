The equilibrium constant K describes the composition ratio for a reaction at equilibrium at a specified temperature. The reaction quotient Q uses the same mathematical form but the mixture's **current** concentrations or partial pressures. Comparing them tells which direction the mixture must change to reach equilibrium.

<TopicLab unitId={7} topicNumber="7.3" title="Compare Q and K" />

<LessonSection title="1. Build the expression from the balanced equation" description="Coefficients become exponents" defaultOpen>

For aA(g) + bB(g) ⇌ cC(g) + dD(g), the concentration expression is:

**Qᶜ = [C]ᶜ[D]ᵈ / ([A]ᵃ[B]ᵇ)**

Use the coefficients in the balanced equation as exponents. Pure solids and pure liquids are omitted because their effective activities remain constant. For Kp, use gas partial pressures instead of molar concentrations.

<QuickCheck question="For N₂(g) + 3H₂(g) ⇌ 2NH₃(g), which is the correct Qc expression?" options={["[N₂][H₂]³/[NH₃]²","[NH₃]²/([N₂][H₂]³)","2[NH₃]/([N₂]+3[H₂])","[NH₃]/([N₂][H₂])"]} correctIndex={1} explanation="Products go in the numerator and reactants in the denominator, with each balanced coefficient used as an exponent." />

</LessonSection>

<LessonSection title="2. Compare Q with K" description="Q = K is the equilibrium condition">

- **Q < K:** the product-to-reactant ratio is too small; net reaction proceeds forward.
- **Q > K:** the product-to-reactant ratio is too large; net reaction proceeds in reverse.
- **Q = K:** the mixture is at equilibrium.

This comparison predicts direction, not how quickly equilibrium is reached.

<WorkedExample title="Worked example: determine direction">
For a reaction, Kc = 4.0 and the current Qc = 0.50. Since Qc < Kc, the mixture has too little product relative to the equilibrium ratio. The net reaction proceeds toward products until Qc reaches 4.0.
</WorkedExample>

<LessonSection title="3. Calculate Q and compare it with K" description="Same expression, different snapshot">

For aA + bB⇌ cC + dD, Qc = ([C]^c[D]^d) / ([A]^a[B]^b) using current concentrations. K has the same form but uses equilibrium concentrations. Pure solids and pure liquids are omitted. Compare the numerical values at the same temperature: Q < K means net reaction proceeds right; Q > K means it proceeds left; Q = K means the mixture is at equilibrium.

<WorkedExample title="Worked example: calculate direction">
For H₂(g) + I₂(g)⇌2HI(g), suppose Kc = 16 and the current concentrations are [H₂] = 0.20 M, [I₂] = 0.20 M, [HI] = 0.40 M. Then Qc = (0.40)^2 / [(0.20)(0.20)] = 4.0. Since Q < K, the net reaction proceeds toward HI until Q rises to 16.

</WorkedExample>

The direction prediction is not based on which side has more moles or larger concentrations individually. It comes from the full ratio with stoichiometric exponents. Never compare Q and K from different temperatures without accounting for the change in K.

<LessonSection title="4. Recalculate Q immediately after a disturbance" description="A changed concentration changes Q first; the system then responds">

Suppose `A(aq) + B(aq) ⇌ C(aq)` is at equilibrium with `[A] = 0.20 M`, `[B] = 0.20 M`, and `[C] = 0.80 M`. Then `Kc = Qc = 0.80/[(0.20)(0.20)] = 20`.

If more A is added so that its concentration instantly doubles to 0.40 M, B and C have not yet had time to respond. The new reaction quotient is `Qc = 0.80/[(0.40)(0.20)] = 10`. Since Q is now below K, the net reaction proceeds right, consuming some A and B and producing more C. At the new equilibrium Q returns to 20, but the equilibrium concentrations are different from the original values.

This sequence is the precise meaning of a shift: the disturbance changes the current mixture and therefore Q; the reaction then changes composition until Q = K again. Do not say that K changes when a reactant is added at constant temperature.

<LessonSection title="5. Use Q and K without confusing a ratio with a rate" description="Q predicts the net direction, not how quickly equilibrium is reached">

The reaction quotient Q has the same mathematical form as K, but it uses the current mixture. Compare Q with K at the same temperature: if Q < K, the forward reaction must increase the product-to-reactant ratio; if Q > K, the reverse reaction must decrease it; if Q = K, the mixture is at equilibrium. This comparison does not tell you the numerical reaction rate or the time required to reach equilibrium.

<WorkedExample title="Worked example: calculate direction for a non-1:1 reaction">

For `N₂(g) + 3H₂(g) ⇌ 2NH₃(g)`, `Qp = (PNH₃)²/(PN₂·PH₂³)`. If the current partial pressures are 0.20 atm NH₃, 0.50 atm N₂, and 0.40 atm H₂, then `Qp = (0.20)²/[(0.50)(0.40)³] = 0.04/0.032 = 1.25`. If Kp = 4.0 at that temperature, Qp < Kp, so the net reaction proceeds right. The cubic H₂ term is essential; using an unexponentiated pressure would give the wrong comparison.

</WorkedExample>
