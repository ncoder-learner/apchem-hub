An equilibrium constant is calculated from the composition **at equilibrium**, not from arbitrary starting concentrations. The balanced equation determines the expression; measured equilibrium values supply the numbers.

<TopicLab unitId={7} topicNumber="7.4" title="Calculate K" />

<LessonSection title="1. Substitute equilibrium values carefully" description="The expression must match the reaction as written" defaultOpen>

For aA + bB ⇌ cC + dD, substitute equilibrium concentrations into Kc = [C]ᶜ[D]ᵈ/([A]ᵃ[B]ᵇ). Raise each concentration to its coefficient's power before dividing. Pure solids and liquids are not included.

<WorkedExample title="Worked example: calculate Kc">
For H₂(g) + I₂(g) ⇌ 2HI(g), suppose equilibrium concentrations are [H₂] = 0.20 M, [I₂] = 0.20 M, and [HI] = 0.80 M.

Kc = [HI]²/([H₂][I₂]) = (0.80)²/((0.20)(0.20)) = 0.64/0.040 = **16**.
</WorkedExample>

<QuickCheck question="For A(g) + 2B(g) ⇌ C(g), [A]eq = 0.50 M, [B]eq = 0.20 M, [C]eq = 0.10 M. What is Kc?" options={["0.10/(0.50 × 0.20)","0.10/(0.50 × 0.20²)","(0.50 × 0.20²)/0.10","0.10/(0.50 + 2 × 0.20)"]} correctIndex={1} explanation="Kc = [C]/([A][B]²) = 0.10/(0.50 × 0.040) = 5.0." />

</LessonSection>

<LessonSection title="2. Keep the reaction equation fixed" description="Changing coefficients changes the numerical K">

If a reaction is reversed, the new equilibrium constant is 1/K. If all coefficients are multiplied by n, the new constant is Kⁿ. These relationships follow because the reaction expression changes with the stoichiometric exponents.

<WorkedExample title="Worked example: reverse the reaction">
If A ⇌ B has K = 5.0, then B ⇌ A has K' = 1/5.0 = 0.20. Reversing the reaction swaps numerator and denominator in the expression.
</WorkedExample>

<QuickCheck question="If the balanced equation is doubled and the original K is 3.0, what is the new K?" options={["1.5","3.0","6.0","9.0"]} correctIndex={3} explanation="Doubling all coefficients squares every term in the expression, so K' = K² = 9.0." />

</LessonSection>

<LessonSection title="3. Calculate K from equilibrium data, not initial amounts" description="The equilibrium expression uses the composition after the system settles">

Write the balanced equation first. Its coefficients become exponents in K, and pure solids and pure liquids are omitted. Substitute equilibrium concentrations or partial pressures—not the initial values unless the data explicitly state that the system is already at equilibrium. K is a number for the reaction as written at a particular temperature; reversing the equation gives 1/K.

<WorkedExample title="Worked example: use equilibrium concentrations">
For A(g) + B(g)⇌2C(g), equilibrium concentrations are [A] = 0.20 M, [B] = 0.10 M, and [C] = 0.40 M. Then Kc = [C]^2 / ([A][B]) = (0.40)^2 / [(0.20)(0.10)] = 8.0. The squared [C] is required by its coefficient 2.

</WorkedExample>

If the equation is multiplied by n, the new equilibrium constant is K_new = K^n. If the equation is reversed, it is 1 / K. These transformations follow from changing the exponents and ratio, not from changing the chemistry at a fixed temperature.

<QuickCheck question="A reaction has Kc = 5.0. What is Kc for the same reaction written in reverse?" options={["−5.0","0.20","5.0","25"]} correctIndex={1} explanation="Reversing a reaction swaps numerator and denominator, so the new equilibrium constant is 1/K = 1/5.0 = 0.20." />

</LessonSection>


<LessonSection title="4. Calculate K from an ICE table when only one equilibrium amount is given" description="Stoichiometric changes reconstruct the missing equilibrium concentrations">

Suppose `A(aq) + B(aq) ⇌ C(aq)` begins with `[A]₀ = [B]₀ = 1.00 M` and `[C]₀ = 0`. At equilibrium, a measurement gives `[C] = 0.400 M`. Because the reaction consumes A and B in a 1:1 ratio, each reactant decreases by 0.400 M: `[A]eq = [B]eq = 0.600 M`.

The equilibrium constant is then `Kc = [C]/([A][B]) = 0.400/[(0.600)(0.600)] = 1.11`. The initial concentrations are used to reconstruct the changes, but they are not substituted directly into Kc unless they happen to equal equilibrium values.

<WorkedExample title="Worked example: why the equilibrium row matters">

If you incorrectly used the initial concentrations, you would calculate `Q = 0/[(1.00)(1.00)] = 0`, not K. That value describes the initial mixture before product has formed. K must be calculated from the equilibrium concentrations after the system has adjusted.

</WorkedExample>
