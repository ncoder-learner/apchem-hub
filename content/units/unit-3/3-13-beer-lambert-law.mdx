# Absorbance can quantify concentration

The Beer–Lambert law relates absorbance to concentration:

**A = εℓc**

A is absorbance (dimensionless), ε is molar absorptivity, ℓ is path length (commonly cm), and c is molar concentration. At a fixed wavelength, with the same absorbing species and path length, absorbance is directly proportional to concentration within the useful linear range.

<Unit3Visual kind="beer-lambert" />

<LessonSection title="1. Read an absorbance graph" description="Slope and proportionality" defaultOpen>

A plot of absorbance versus concentration should be linear for an appropriate dilute range. If path length and wavelength are fixed, doubling concentration doubles absorbance under the model. A calibration curve can be used to estimate the concentration of an unknown sample from its measured absorbance.

<LessonSection title="2. Solve for an unknown" description="Use the calibration relationship">

If ε = 150 L·mol⁻¹·cm⁻¹, ℓ = 1.00 cm, and A = 0.300, then:

**c = A / (εℓ) = 0.300 / ((150)(1.00)) = 2.00 × 10⁻³ M**

Track units and significant figures. Do not compare absorbances measured at different wavelengths as though ε were unchanged unless the problem supports that assumption.

</LessonSection>

<LessonSection title="3. AP-style experiment interpretation" description="Control variables and support claims">

When interpreting spectrophotometry, state which variables are controlled (wavelength, path length, species) and use the graph or measured absorbance as evidence. If a calibration plot bends away from linearity, do not force the linear model beyond its valid range; concentration may be too high or the experimental conditions may have changed.

</LessonSection>
