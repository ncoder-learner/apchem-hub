Weak acids and bases react only partially with water. Their equilibrium concentrations therefore cannot be found by treating the initial acid or base concentration as fully ionized.

<LessonSection title="1. Write the equilibrium expression" description="Products over reactants, excluding liquid water" defaultOpen>

For a weak acid HA:

HA + H₂O ⇌ H₃O⁺ + A⁻

Ka = [H₃O⁺][A⁻] / [HA]

For a weak base B:

B + H₂O ⇌ BH⁺ + OH⁻

Kb = [BH⁺][OH⁻] / [B]

Pure liquid water is omitted from the equilibrium expression. A larger Ka means a stronger acid among comparable acids; a larger Kb means a stronger base.

</LessonSection>

<LessonSection title="2. Set up an ICE table" description="Initial, change, equilibrium" defaultOpen>

For an initial concentration C of HA, the idealized table is:
- Initial: [HA] = C; [H₃O⁺] ≈ 0; [A⁻] = 0
- Change: −x; +x; +x
- Equilibrium: C − x; x; x

Then Ka = x²/(C − x). If x is small compared with C, the approximation C − x ≈ C gives x ≈ √(KaC). Use this only if the resulting percent ionization is small (commonly checked against the 5% rule); otherwise solve the quadratic equation.

<WorkedExample title="Estimate pH for a weak acid">
A 0.100 M weak acid has Ka = 1.0 × 10⁻⁵. The small-x estimate gives [H₃O⁺] ≈ √(1.0 × 10⁻⁵ × 0.100) = 1.0 × 10⁻³ M. Therefore pH ≈ 3.00. The estimated ionization is 0.0010/0.100 × 100% = 1.0%, so the approximation is reasonable.
</WorkedExample>

<LessonSection title="3. Relate Ka, Kb, and conjugate strength" description="Conjugates trade acid strength for base strength">

For a conjugate acid–base pair in water at the same temperature, Ka × Kb = Kw. A stronger acid has a weaker conjugate base; a stronger base has a weaker conjugate acid. At 25 °C, pKa = −log Ka, so a smaller pKa corresponds to a stronger acid.

Do not assume a weak acid has a neutral pH. Its pH depends on its concentration and Ka. Likewise, weak does not mean dilute; strength describes extent of ionization, while concentration describes amount per volume.

</LessonSection>

<LessonSection title="4. Solve a weak-base equilibrium and connect conjugate strength" description="The same equilibrium logic applies to bases, with OH⁻ as the tracked product">

For a weak base B, write `B + H₂O ⇌ BH⁺ + OH⁻`. If the initial base concentration is C and x reacts, then `[B]eq = C − x`, `[BH⁺]eq = x`, and `[OH⁻]eq = x`. Therefore:

`Kb = x²/(C − x)`.

<WorkedExample title="Worked example: calculate pH for a weak base">

A 0.100 M weak base has `Kb = 1.8×10⁻⁵`. Using the small-x estimate, `[OH⁻] ≈ √(KbC) = √(1.8×10⁻⁶) = 1.34×10⁻³ M`. Then `pOH = −log(1.34×10⁻³) = 2.87`, and at 25°C `pH = 14.00 − 2.87 = 11.13`. The percent ionization is about `(0.00134/0.100)×100% = 1.34%`, so the approximation is reasonable.

</WorkedExample>

The conjugate acid BH⁺ is weak as well. For the pair at 25°C, `Ka(BH⁺)Kb(B) = Kw`, so `Ka(BH⁺) = (1.0×10⁻¹⁴)/(1.8×10⁻⁵) = 5.6×10⁻¹⁰`. A relatively larger Kb corresponds to a weaker conjugate acid. Strength is an equilibrium property; it is not the same as concentration.

<LessonSection title="5. Decide when the small-x approximation is valid" description="Check the approximation after solving, rather than assuming it">

For a weak acid HA with initial concentration C, the equilibrium expression is `Ka = x²/(C − x)`, where x is the amount ionized. If x is small compared with C, then `C − x ≈ C` and `x ≈ √(KaC)`. The approximation simplifies the algebra, but it must be tested after calculating x. A commonly used AP-level check is whether x/C is less than about 5%; if not, solve the quadratic equation exactly.

<WorkedExample title="Worked example: calculate and test percent ionization">

A 0.100 M weak acid has `Ka = 1.0×10⁻⁵`. The estimate is `x ≈ √[(1.0×10⁻⁵)(0.100)] = 1.0×10⁻³ M`. Percent ionization is `(x/C)×100% = (0.0010/0.100)×100% = 1.0%`, so the approximation is reasonable. The pH is approximately `−log(1.0×10⁻³) = 3.00`. The initial concentration is not the equilibrium hydronium concentration; only the ionized amount contributes to [H₃O⁺] in this model.

</WorkedExample>
